# Mescla Elemental — página de login

Página pública de login (Google + e-mail/senha via Supabase Auth) do jogo Mescla Elemental, publicada pelo GitHub Pages em https://danieldss90.github.io/mescla-elemental-login/. O jogo abre esta página com um código de sessão; ela grava o perfil em `player_profiles` e o jogo o busca pela RPC `get_login_profile`. Ver `docs/LOGIN_E_PLACAR.md` no repositório (privado) do jogo.
